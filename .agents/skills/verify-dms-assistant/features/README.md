# Feature map

One file per feature. `covers:` lists the source globs it owns, `docs:` the pages a verdict judges, and `e2e/journeys/<feature>.mjs` its journeys. `dms-control map` checks that every user-facing file is covered and that every feature has its journeys and existing docs pages.

| Feature | What the user does | Journeys |
|---|---|---|
| [smoke](smoke.md) | The fixed journey every verdict runs: open Settings, read the status, change a default. | smoke |
| [lifecycle](lifecycle.md) | The backend starts the sidecar, reports its status, restarts it, gives up after repeated crashes, and starts none with `DMS_ASSISTANT=0` or on a production start. | the-status-reads-ready-and-names-the-sidecar, a-restart-gives-a-new-sidecar-and-keeps-what-you-set, a-sidecar-that-keeps-dying-gives-up-and-the-banner-offers-a-restart, the-sidecar-listens-on-loopback-only, an-openai-api-key-is-ignored-with-one-warning-per-start, an-idle-sidecar-exits-after-its-idle-timeout-and-the-next-probe-starts-it, dms-assistant-0-starts-the-backend-without-a-sidecar, a-backend-that-crashed-leaves-no-sidecar-for-long, a-production-start-runs-no-sidecar, a-development-start-adds-the-dms-server-to-mcp-json-and-keeps-the-rest |
| [access](access.md) | Every route answers the owner; the sidecar calls its own routes with its own token; the dashboard forwards `/ai/**`. | every-owner-route-refuses-nobody-and-a-member, the-sidecar-routes-answer-only-the-sidecar, the-dashboard-origin-forwards-ai-with-the-session |
| [settings](settings.md) | The defaults of new conversations in the AI and Builder sections and the Guard rails card (each agent's default mode, Safe mode), saved as they are made, the guard rails only with the assistant UI's header. | the-defaults-are-the-documented-ones, every-setting-saves-alone-and-survives-a-restart, a-guard-rail-needs-the-assistant-uis-header, a-stored-settings-file-is-read-back-by-the-next-start, a-value-outside-the-options-is-refused-and-changes-nothing, the-page-saves-each-change-as-you-make-it, the-page-disables-what-this-machine-cannot-do, the-menus-and-choices-offer-exactly-the-documented-options, every-label-of-the-page-is-the-documented-one, usage-counts-nothing-before-a-conversation, usage-counts-the-stored-tokens-of-the-last-14-days |
| [activity](activity.md) | The audit log of every tool call, its tabs, periods and export. | an-empty-log-says-so-and-exports-its-header, the-log-says-when-the-assistant-is-down, the-log-lists-every-call-with-its-tabs-filters-and-pages, the-page-shows-the-log-its-tabs-periods-and-more-rows, a-row-opens-its-detail-with-the-arguments-trail-output-and-diff, the-export-holds-every-row-whatever-the-tab-and-the-period, the-export-stops-at-10000-rows, a-list-page-holds-200-rows-however-many-are-asked |
| [changes](changes.md) | Change sets with their diff, Undo and Redo. | no-change-set-yet-says-so, the-changes-say-when-the-assistant-is-down, the-list-searches-filters-and-opens-a-set-with-its-diff, undo-and-redo-restore-the-files-and-record-who-did-it, undoing-a-set-lists-the-later-sets-on-the-same-files, change-sets-older-than-the-retention-are-dropped-when-the-assistant-starts |
| [onboarding](onboarding.md) | The first-run popup's routes: where each login stands, a pasted Claude token, the provider choice. | the-state-says-where-each-login-stands-and-offers-one-codex-sign-in, a-provider-choice-is-saved-and-an-unknown-one-is-refused, a-pasted-claude-token-is-checked-without-being-stored-or-echoed |
| [codex](codex.md) | The ChatGPT sign-in that Codex runs on. | signed-out-the-banner-offers-the-sign-in-and-the-paste, a-pasted-address-is-checked-before-anything-is-stored |

The smoke journey runs on every verdict.
