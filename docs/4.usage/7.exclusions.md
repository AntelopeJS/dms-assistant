The Exclusions page (`/modules/ai/exclusions`) lists the data **Analyst** may never read. Only owners can open it. It applies to Analyst only: Builder runs in development, for owners, and is not filtered.

## What an exclusion covers

An exclusion is a data route and a field. It applies to every table that reads that route: excluding `email` on the customers route hides it on every page that lists customers. There is one list for the project, shared by every workspace.

When a field is excluded:

- Analyst never receives its values, in the rows it reads, the datasets it loads or what it computes from them.
- Analyst sees the column as redacted, so it can tell the user the column exists and is excluded.
- A filter or a sort on the field is refused.
- Free-text search is refused on any table reading a route with an exclusion, because a search could match the excluded field.

If the list cannot be read, Analyst reads no data until it can.

## Manage the list

Select **Add exclusion**, then pick a page, one of its tables, and a column. The list offers the pages, tables and columns you can see.

Each entry shows the pages and tables it covers. An entry whose route or field no longer appears anywhere you can see is marked **Not found**. It stays in the list and stays enforced until you remove it.
