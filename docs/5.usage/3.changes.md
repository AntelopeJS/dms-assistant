Each assistant turn that changes the project is saved as a change set. A change set holds a checkpoint of the files before the turn and the diff the turn produced. The Changes page, `/modules/ai/changes`, lists them, and `?set=<id>` opens one.

![The Changes page on a new project, with its search, the All, Safe and Code filter, and the empty state](../images/captures/ai-changes.webp)

## Review a change set

1. Open **Changes** in the **Assistant** menu of the dashboard.
2. To narrow the list, type in **Search files or changes**, which matches titles and file paths, or pick **All**, **Safe** or **Code**.
3. Click a change set in the list.

The change set opens on **Change set #3 · checkpoint before** and its title. Under them, rows show **Asked by**, **Agent · scope**, **Approvals** (such as **1 needed · 3 Builder ops**) and **Checks** (**Typecheck passed**, **Typecheck failed** or **Typecheck skipped**). The diff of each file follows. A banner warns when another chat changed files at the same time, so the set may hold its changes too.

**Conversation** opens the chat the set came from. **Open page** opens the page the set changed, when there is one.

## Undo a change set

1. Open the change set, then click **Undo change set**.
2. Read the dialog, **Undo change set #3?**, which says how many files it restores.
3. If later change sets touched the same files, the dialog lists them. **Also undo the later change sets** is on by default. If you turn it off, their lines stay, and the code may not compile.
4. Click **Undo**.

The assistant restores the files to the checkpoint and the page reloads. A toast confirms the undo and offers **Redo**.

## Redo a change set

To put an undone set back, open it and click **Redo**. The files return as the assistant left them.

Each undo and redo records the signed-in user's name, or their email when they have no name. A change set older than the **Undo history** setting, 7, 30 or 90 days, can no longer be undone. See [Settings](/docs/modules/assistant/usage/settings#builder).

## If change sets are off

When Git is missing on the machine, the page says **Change sets are off**, and the assistant saves no checkpoint. Install Git, then restart the project.
