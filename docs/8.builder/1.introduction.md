The builder that changes a DMS project's pages, tables and data sources ships in `@antelopejs/dms`. The DMS implements [`@antelopejs/interface-dms-builder`](https://github.com/AntelopeJS/dms/tree/main/packages/interface-dms-builder/docs) and serves the builder tools through its [MCP server](/docs/ai-and-claude-code/mcp-server), so a project gets them whether or not it installs this module. Every change the builder makes is TypeScript in your sources, and the change compiles before it is written.

`@antelopejs/dms-assistant` keeps one part of the builder: the routes under `/api/builder/database` that connect a database you already run. **Start from an existing database** in the assistant's onboarding popup calls them to wire the database into the project, analyse its tables and map them into pages. [Extending](/docs/modules/assistant/builder/extending) lists them.

::important
The routes rewrite source files, so by default the module mounts them only in development (`ajs project dev`, with or without `-w`). A started build (`ajs project start`) has none unless [`builder.api.enabled`](/docs/modules/assistant/builder/configuration) forces them on.
::

## Who can use it

Every route requires an authenticated tenant owner.

## Works with the AI assistant

The assistant changes pages through the builder tools of the DMS MCP server. In **Safe mode**, its default, those tools are the only way it writes, so the builder typechecks every change and you can undo it from **Changes**.
