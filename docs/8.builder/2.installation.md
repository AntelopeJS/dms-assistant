---
title: Installation
description: Add the builder to a DMS project and check that its API answers.
mode: how-to
---

You need a working DMS project and a tenant-owner account. When you finish, the builder answers under `/api/builder`, and the AI assistant changes pages through it.

::steps
### Add the module

```bash [Terminal]
ajs project modules add @antelopejs/dms-assistant
```

The module needs a module that implements `@antelopejs/interface-api` for its HTTP routes, and the database and DMS interfaces the project already uses. The [README compatibility table](https://github.com/AntelopeJS/dms-assistant#requirements) lists the interface ranges it supports. Its frontend needs a `@antelopejs/dms-frontend` renderer in the range of `engines["@antelopejs/dms-frontend"]` in `frontend-vue/package.json`.

### Point it at your sources

The builder edits the project it runs in. If the backend's working directory is not the app's source root, set `builder.projectRoot` in the entry that `ajs project modules add` wrote:

```ts fragment [antelope.config.ts]
"dms-assistant": {
  source: { /* … */ },
  config: {
    builder: {
      projectRoot: __dirname,
    },
  },
},
```

### Run the project in development

Start the backend from the project directory:

```bash [Terminal 1, backend]
pnpm exec ajs project dev -w
```

When the backend has started, start the frontend in a second terminal:

```bash [Terminal 2, frontend]
pnpm exec ajs dms dev
```

The backend registers the module's frontend, so the frontend must start after it.

### Check the builder

Send `GET /api/builder/status` to the backend as a tenant owner. It answers `{ ok: true, projectRoot }`, with the source root the builder edits. If it answers `404`, read [the FAQ](/docs/modules/assistant/builder/faq#every-apibuilder-route-answers-404) before you turn the builder on in a production process.
::

To make a first change, ask the assistant to rename a card on one of your pages. The new title appears in the page's source file and, once the backend has reloaded, on the page.

::tip
The repository's playground (`playground`) loads the module with a demo `orders` table and a **Board** page that holds a chart to configure. In that directory, run `pnpm install --ignore-workspace`, then `pnpm dev` and `pnpm frontend:dev`.
::
