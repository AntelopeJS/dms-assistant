## Every /api/builder route answers 404

The builder is off in this process, so the module never imports its routes controller. [When the builder is on](/docs/modules/assistant/builder/configuration#when-the-builder-is-on) lists the commands that turn it on.

Do not turn the builder on in a deployment only to make the routes answer. With `builder.api.enabled: true`, tenant owners can rewrite the sources of that environment.

## A write fails with "stale"

The page changed on disk after the client read it, or while the write ran. Another client, the AI assistant or a hand edit wrote to it. Nothing is written. Read the page again with `GET /api/builder/page`, then retry the write with the new `version` as `expectedVersion`.

## A write fails on the typecheck

The builder writes only code that compiles across the whole project. If a write fails with `typecheck_failed`, nothing is written, and the error lists each diagnostic with its file and line. A type error elsewhere in the project also blocks the write, even when the change did not cause it. Fix that error first, then retry.

## A chart reads nothing from its old route

The DMS serves the routes of a page under `/dms/pages<page path>`, not at the page's own path. A data source the builder wrote answers at that address. A block whose `fetchUrl` names the page's own path (`/shop/board/stats/revenue`) gets no data.

To fix the block, point its `fetchUrl` at `/dms/pages/shop/board/stats/revenue`. `pageRoutePath(page, endpoint)` from `@antelopejs/interface-dms/page` builds that path.

## A role lost access to a block that moved

The DMS names a block permission after the place where the block sits. Moving or renaming a block gives it a new permission. To restore access, grant the new permission to the role in **Roles**.

## Where does the builder write?

The builder writes under `projectRoot`, in the project's own sources:

- pages as `PageController` classes,
- tables as `Table`, `DataController` and model files,
- data sources as model methods and page routes.

Commit these files like any other code.
