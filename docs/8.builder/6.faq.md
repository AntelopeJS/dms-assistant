## Every /api/builder/database route answers 404

The routes are off in this process, so the module never imports their controller. [When the routes are on](/docs/modules/assistant/builder/configuration#when-the-routes-are-on) lists the commands that mount them.

Do not turn the routes on in a deployment only to make them answer. With `builder.api.enabled: true`, tenant owners can rewrite the sources of that environment.

## A mapping fails on the typecheck

The builder writes only code that compiles across the whole project. If `POST /api/builder/database/map` fails with `typecheck_failed`, nothing is written, and the error lists each diagnostic with its file and line. A type error elsewhere in the project also blocks the write, even when the mapping did not cause it. Fix that error first, then retry.

## Where does connecting a database write?

Connecting a database writes under `projectRoot`, in the project's own sources:

- the driver module and the module that holds the tables, in `antelope.config.ts`,
- the connection's URL variable, in `.env`,
- the mapped tables as `Table`, `DataController` and model files, and their pages as `PageController` classes.

Commit these files like any other code, except `.env`.
